# Store Inventory Management System

An Excel-based inventory and sales management system I built to keep track of products, inventory, sales, pricing, and profit.

## About the Project

I created this project to make it easier to manage store inventory and sales in one Excel workbook instead of keeping information in separate files or manually tracking everything.

The workbook has different sections for adding and updating products, checking inventory, recording sales, and viewing sales history. It also uses formulas and lookups to automatically pull information and calculate pricing and profit.

## Features

- **Check Inventory** – Search for products using Item ID and view inventory information.
- **Add Inventory** – Add new products and their pricing information to the inventory.
- **Update Inventory** – Find existing products and update their information.
- **Record Sale** – Record products sold and quantities.
- **Sales History** – Keep track of previous sales and related profit information.
- **Pricing & Profit Calculations** – Calculate product costs, pricing, and profit using Excel formulas.

## Workbook Structure

| Worksheet | Description |
|---|---|
| **Check Inventory** | Search for and view product information |
| **Record Sale** | Record product sales and quantities |
| **Sales Inventory** | View sales and inventory information |
| **Sales History** | Keep track of previous sales |
| **Add Inventory** | Add new products |
| **Update Inventory** | Update existing products |
| **Inventory** | Main inventory data |
| **Data** | Supporting product and pricing data |

For this project, I focused on organizing the inventory data and creating a simple workflow for managing products and sales.

Some of the main things I worked on include:

- Setting up the inventory database
- Creating formulas for pricing and profit calculations
- Building lookup functions for finding product information
- Creating separate workflows for adding and updating inventory
- Setting up a sales recording process
- Maintaining a sales history
- Organizing the workbook so that the data is easier to manage and use
